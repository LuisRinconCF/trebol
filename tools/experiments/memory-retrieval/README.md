## Queries

Five fixed examples: `amber otter habitat` (exact); `habitat for amber otter` (reordered); `where does the amber otter inhabit the quiet marsh today` (verbose); `ambr ottr habtat` (typo); and `reverse a release` (synonym). Expected result is `otter` for the first four and `deploy` for the last. The same repository-verified corpus includes `fox`, `heron`, `billing` distractors and an excluded worktree duplicate. See `live-five.mjs` lines 36–50. There is no dedicated unrelated-query negative case in this five-example matrix.

## Methods

The unchanged `control` uses the repository's current strict-first, partial-two-concept PageIndex ranking. Eight alternative *candidate implementations* replace only `rankedSections` in a temporary copy: exact phrase; any token (minimum two); all tokens; crude suffix stem; word-prefix; edit distance ≤2; character trigrams; and explicit four-entry query expansion. They are not merely query rewrites. All variants use the same stored records, real tool and child. The generated `trigram` implementation returned no candidates on all five examples; treat it as an unsuccessful implementation, not as evidence that trigrams generally cannot work. The `expanded` dictionary is hand-coded to this fixture and not general semantic search. See `live-five.mjs` lines 19–35, 54–65, 81–99.

## Child

Each nonempty candidate set goes through `memory_history.execute` → `selectTaskMemory` → real `pi -p --no-session --no-extensions --no-tools --tools memory_browse,memory_read,memory_select` with a snapshot and receipt. The driver supplies `pi.exec` backed by an actual spawned `env pi`, not a synthetic selection. The child has a 45-second deadline; its worker enforces browse/read/select and disallows selection of unread keys. `results.jsonl` records the offered cards in order, bounded child stdout/stderr, exit code, receipt, final tool result and elapsed milliseconds. A `no-result` with no child trace means candidate generation stopped the flow. See `live-five.mjs` lines 67–79, 91–104; `.pi/lib/state/memory-retrieval-worker.ts:17-35`.

## Decision

For **these five examples**, edit-distance candidate ranking is the best-supported general candidate: it recovered the typo while retaining the three control hits, and the real child rejected the offered fox distractor. It still missed the synonym. Explicit expansion found the synonym only because the dictionary named that exact pair, and one child failed upstream. No production strategy was changed; selection is provisional until a larger real-query set includes negative, ambiguous and crowded-card cases and repeat runs. The original tool's `no-result` can still occur before any child. `git diff --check` and `node --check` on both new scripts passed; no unit tests were added or run for this benchmark.
